В работе сделана информационная система для объектов лабораторных работ. Клиент только показывает данные и отправляет запросы. Создание, изменение, удаление и специальные операции выполняет сервер Jakarta EE и фиксирует результат в PostgreSQL.

Данные разложены по таблицам в соответствии с классами варианта. У вспомогательных классов в базе есть суррогатный ключ: без него нельзя выбрать уже существующий объект и перенести связи при удалении. Идентификатор `LabWork` имеет тип `INTEGER` и выдаётся столбцом `GENERATED BY DEFAULT AS IDENTITY`. Дата создания проставляется в `@PrePersist` и не приходит из формы. Ограничения из комментариев к полям повторены аннотациями Jakarta Validation и ограничениями `CHECK` в `db/init.sql`. Поставщик JPA — EclipseLink, общий кэш отключён, чтобы второй пользователь не читал устаревшую запись.

Связь «программа дисциплины» хранится отдельно от обязательного поля `discipline`. Специальные операции не посчитаны в Java: сервис вызывает функции `avg_minimal_point`, `lab_works_by_description`, `unique_minimal_points`, `decrease_labwork_difficulty` и `add_hardest_labworks`. Понижение сложности идёт по порядку `TERRIBLE`, `IMPOSSIBLE`, `VERY_HARD`, `HARD`, `NORMAL`. Десять самых сложных отбираются этой же шкалой, при равенстве — по большему `minimalPoint`.

Интерфейс разделён меню: список, создание, карточка объекта и экран специальных операций. Изменение открывается диалогом и из таблицы, и из карточки. Фильтр строковых колонок требует полного совпадения; поиск подстроки в описании вынесен в отдельную операцию. Если при удалении есть ссылки, пользователь выбирает объект того же типа, сервер переносит связи и только потом удаляет запись.

Роли разделены: любой вошедший пользователь видит все объекты, менять их может администратор. После успешной транзакции сервер рассылает событие по WebSocket, и открытые клиенты обновляют список и карточку.

Для локального запуска база поднята в Docker под именем хоста `pg`, базой `studs` и пользователем `studs`, как на кафедральном сервере. Приложение работает в Payara Micro, где уже есть EclipseLink.
